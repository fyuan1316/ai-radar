## 节点 & kubelet

节点侧本周主要是 **1.38 方向的 KEP 起步**(实现尚未落地,先占坑),对我们产品有中长期影响的几条:

- **Dynamic Containers / Dynamic Pod Mutation(KEP-5972,alpha)** —— "让容器可变":引入运行中 Pod 的乐观执行与分层资源委派,目标是让容器规格在 Pod 运行期可动态修改。对"推理服务热更新 sidecar / 动态注入"这类场景是原生抓手,值得从设计阶段跟。https://github.com/kubernetes/enhancements/pull/6169
- **Hugepages Reservation(KEP-6252,新)** —— kubelet 的 `--system-reserved` / `--kube-reserved` 支持计入 hugepages。大页内存密集型负载(部分推理/HPC)的节点资源核算更准。https://github.com/kubernetes/enhancements/pull/6253
- **PSI 指标进 Summary API + PSI 驱动节点动作(KEP-4205,设计合入)** —— Pressure Stall Information 进 kubelet Summary API,并可据 PSI 触发节点级动作(如驱逐/标记)。对节点级 CPU/内存/IO 压力可观测与自愈是实打实的能力。https://github.com/kubernetes/enhancements/pull/4230
- **Pod-level Checkpoint/Restore 增 GPU 支持(KEP-6274,alpha)** —— CRIU 式 Pod 级检查点/恢复补 GPU 支持。核心 C/R 是通用节点能力,GPU 部分偏 AI;此处仅记一笔,GPU 细节归 k8s-ai-infra。https://github.com/kubernetes/enhancements/issues/6274

## 策略 & 安全

- **Kyverno `v1.19.0` GA(8/20)** —— 本周策略侧唯一大件,几条对我们(多租户/安全合规)有用的:
  - **修 CVE-2026-32280**:限制中间证书链,防镜像验证/证书处理被利用。https://github.com/kyverno/kyverno/pull/15858
  - **CEL 原生策略族全面成熟**:ValidatingPolicy / MutatingPolicy(mpol)/ GeneratingPolicy(gpol)/ DeletingPolicy(dpol)/ ImageValidatingPolicy(ivpol)本版大量补齐(mpol 支持 target conditions/subresource/auditAnnotations、gpol 支持 server-side apply/YAML 模板/auditAnnotations、ivpol 私有 Sigstore/Fulcio keyless 验证与镜像验证缓存复用)。这是 Kyverno 面向 CEL 的下一代策略主线。
  - **弃用与瘦身**:legacy `kyverno.io` 老策略类型开始打弃用告警(PSS 默认迁到新类型),并**彻底移除 `kyverno-json` 支持**(api/cli/test 全线)。升级前要评估现有老格式策略的迁移。https://github.com/kyverno/kyverno/pull/16792
  - **对齐上游原生策略**:新增支持在 **k8s 1.36 上跑原生 MutatingAdmissionPolicy v1**。https://github.com/kyverno/kyverno/pull/16703
  - Go 工具链升 1.26.3 修 CVE-2026-39836。https://github.com/kyverno/kyverno/pull/16361
- **Gatekeeper**:本窗口无新 release。
- **CVE 直读**:Kyverno CVE-2026-32280(中间证书)+ Go CVE-2026-39836(工具链)本版已修;无 k8s 核心侧 CVE 公告。
