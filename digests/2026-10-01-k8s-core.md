# K8s 自身核心周报 2026-10-01

窗口:2026-09-24 → 2026-10-01

## 摘要(3 条以内)

1. **v1.38 周期正式开张**:`v1.38.0-alpha.1` 2026-09-29 打 tag(https://github.com/kubernetes/kubernetes/releases/tag/v1.38.0-alpha.1)。主题是「**后量子签名(ML-DSA)全链路铺开**」+「**多个 GA 锁定与 feature gate 永久化**」。有两处 gate 移除会**卡升级**(`SeparateTaintEvictionController`、`PodSchedulingReadiness`),升级前必须先改 `--feature-gates`。→ **deep-dive 该跑了**(新 minor 的 rc 前首个 alpha)。
2. **Runtime 层本周两件都影响生产稳定**:containerd 一次性放出 5 条分支补丁(v2.4.1/2.3.6/2.2.9/2.0.13/1.7.36,2026-09-24)修安全漏洞 **CVE-2026-53493**;runc `v1.5.2`(2026-09-25)绕过 **Linux kernel v6.17 起的 cgroup v2 内核 bug**——该 bug 会让内核越界写 runc 的用户态结构体,导致配置 device 规则时 runc **随机崩溃**。用 6.17+ 内核 + cgroup v2 的集群优先升 runc。
3. **非 AI 的 KEP 信号集中在 apiserver 可扩展性与自动扩缩容**:慢 watch 流「暂停重连而非终止」(KEP-6268)、apiserver 写吞吐(KEP-6404)、Controller Leader Election Recovery(KEP-6361)、HPA 可配置 sync period(KEP-6003)+ fallback 策略(KEP-5679);存储侧多条 CSI/卷能力进 beta。

> **与 `k8s-ai-infra` 边界**:本周 enhancements 里 DRA / WAS / gang / CompositePodGroup / TAS 的晋级(Workload Aware Preemption GA、DRA Consumable Capacity GA、DRA List Types / Node Allocatable beta、Job×WAS beta、PlacementFeasible 扩展点)全部归 `k8s-ai-infra`,本任务不重复。唯一溢出到通用 K8s 的:**DRADeviceTaints / DRADeviceTaintRules 在 1.38 GA 锁定**,影响所有用 ResourceClaim 的用户(见下)。

## K8s 核心版本节奏

**v1.38 周期开始**,`v1.38.0-alpha.1`(2026-09-29)。CHANGELOG:https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.38.md。本窗口的增量(系统性版本档案留给 deep-dive):

**⚠️ 升级前必读(Urgent Upgrade Notes)**
- 移除 `SeparateTaintEvictionController` feature gate:taint 驱逐现由独立的 taint-eviction-controller 永久承担,升级前要从 `--feature-gates` 里删掉该 gate;仍可用 `--controllers=-taint-eviction-controller` 关。https://github.com/kubernetes/kubernetes/pull/141789
- 移除 `PodSchedulingReadiness` gate(功能永久开启)。https://github.com/kubernetes/kubernetes/pull/141741
- 移除已锁定的 GA gate `CustomResourceFieldSelectors`、`CRDValidationRatcheting`。https://github.com/kubernetes/kubernetes/pull/141207
- **out-of-tree 调度插件破坏性改动**:用 `NominatedPodsForNode` 的插件,签名首参数现在必须传 `logger klog.Logger`。https://github.com/kubernetes/kubernetes/pull/142118
- 构建切到 **Go 1.27.1**。https://github.com/kubernetes/kubernetes/pull/142176

**GA 锁定**
- 容器 **env files** GA(`EnvFiles` gate 锁定):https://github.com/kubernetes/kubernetes/pull/139115
- **KEP-4858 IP/CIDR 校验收紧** GA,API 类型里 IP/CIDR 的严格校验永久生效:https://github.com/kubernetes/kubernetes/pull/141979
- **DRADeviceTaints / DRADeviceTaintRules** GA 锁定(1.41 移除 gate)——AI 溢出项,影响所有 ResourceClaim 用户:https://github.com/kubernetes/kubernetes/pull/140256

**后量子签名(ML-DSA)主题**(本周期最密集的一条线,横跨 apiserver/kubelet/kubeadm)
- Beta:PodCertificateRequest + `projected` 卷支持请求 ML-DSA 算法签名的 pod 证书:https://github.com/kubernetes/kubernetes/pull/142108
- Alpha:CSR 支持 ML-DSA 签名的 PKCS#10(`CertificateSigningRequestMLDSA` gate):https://github.com/kubernetes/kubernetes/pull/142196
- kubelet `KubeletConfiguration` 可选 ECDSA/RSA/ML-DSA(默认仍 ECDSA-P256):https://github.com/kubernetes/kubernetes/pull/142046
- kubeadm `ClusterConfiguration.EncryptionAlgorithm` 加 ML-DSA-44/65/87:https://github.com/kubernetes/kubernetes/pull/142037

## 调度(kube-scheduler)

通用调度器(WAS/gang/TAS/CompositePodGroup 归 `k8s-ai-infra`):
- **KEP-5598 泛化 rescoring**:新增 `Rescore` 扩展点,给调度框架加通用重打分能力(仍在推进):https://github.com/kubernetes/enhancements/pull/6411
- **KEP-5836 IPPR 抢占 beta**:为「In-Place Pod Resize」场景做调度器抢占的 beta 更新——与 VPA 原地扩缩紧相关(见下):https://github.com/kubernetes/enhancements/pull/6344
- 1.38 已落:新增 `PlacementFeasible` 扩展点(供 out-of-tree 做 PodGroup 可行性评估):https://github.com/kubernetes/kubernetes/pull/141314
- 抢占类 scheduler extender 现在必须处理「空 victim 列表」的候选:https://github.com/kubernetes/kubernetes/pull/135486

## 节点 & kubelet

- **容器 env files GA**(见版本节奏),从文件注入环境变量不再需要 gate。
- **KEP-6318 容器探针可原地更新**(mutable probes):允许在不重建 Pod 的情况下改 probe 配置,1.38 推进中:https://github.com/kubernetes/enhancements/pull/6323
- **KEP-6007 NUMA 利用率感知的 topology manager 策略选项**:给 topology manager 加 NUMA 利用率维度的 policy option:https://github.com/kubernetes/enhancements/pull/6332
- **KEP-5359 workload-controlled swap**:工作负载可控的 swap 使用,文档补齐:https://github.com/kubernetes/enhancements/pull/5569
- **KEP-5714 可选不共享 cgroup namespace**:https://github.com/kubernetes/enhancements/pull/5715
- 新的 conformance 覆盖 `PodReadyToStartContainers` 条件的重置:https://github.com/kubernetes/kubernetes/pull/141460

## 自动扩缩容(VPA / CA / Karpenter)

本周 `kubernetes/autoscaler`、`kubernetes-sigs/karpenter`、`kubernetes-sigs/cluster-api` **均无 release**。KEP 侧动静在 HPA:

- **KEP-6003 可配置 HPA sync period**:HPA 的同步周期将可配,利于大规模集群降 apiserver 压力 / 调快响应:https://github.com/kubernetes/enhancements/pull/6004
- **KEP-5679 HPA fallback 策略**:metrics 不可用时的 fallback 字段(Static / UseMax / UseMin),避免 metrics 断流导致 HPA 乱缩:https://github.com/kubernetes/enhancements/pull/6213
- **VPA / in-place resize 线**:本周无 VPA 自身更新,但 **KEP-5836(IPPR 抢占)进 beta** 是这条线的关键配套——VPA 要在生产真正可用,依赖 in-place pod resize(KEP-1287)及其调度器抢占语义成熟,这条值得继续跟。

## Runtime(containerd / CRI-O / runc)

- **containerd 协同补丁批次**(2026-09-24,一次性覆盖 5 条支持分支):v2.4.1 / v2.3.6 / v2.2.9 / v2.0.13 / v1.7.36。含安全补丁 **CVE-2026-53493**(https://github.com/containerd/containerd/security/advisories/GHSA-pg57-6jwg-q645),并修了几个 CRI 侧稳定性 bug:容器启动清理失败会泄漏 task 导致无法删容器(#14223)、SELinux relabel 不被文件系统支持时建容器失败(#14212)。release:https://github.com/containerd/containerd/releases/tag/v2.4.1
- **runc v1.5.2**(2026-09-25):核心是绕过 **Linux kernel v6.17 引入、v7.2 修复的内核 bug**——在 cgroup v2 上配 device 规则时内核越界写 runc 用户态结构体,导致 runc 内存损坏 / 随机崩溃;另修 eBPF device cgroup 的长期 fd 泄漏、systemd ≥260 `PrivateUsers=full` 下误判 userns 导致启动失败等。release:https://github.com/opencontainers/runc/releases/tag/v1.5.2
- **CRI-O**:本周无 release。

- Gatekeeper / Kyverno 本周**均无 release**。
- **后量子密码学(ML-DSA)是本周期最大的安全主题**——见版本节奏,已铺到 apiserver / kubelet / kubeadm / client-go,产品若有国密 / 合规 / 长周期证书诉求可提前评估。
