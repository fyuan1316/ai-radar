# K8s AI 基础设施周报 2026-10-08

> 窗口:过去 7 天(~2026-10-01 → 2026-10-08)。数据源见 `tasks/k8s-ai-infra.md`。与今日 `k8s-core`、`compute-nv-watch` 有重叠的部分只做指针,不重复展开。

## 摘要(3 条以内)

1. **v1.38 是上游原生调度(WAS 主线)的分水岭**:KEP-4671 Gang Scheduling 与 KEP-5710 Workload-aware Preemption 双双锁定 **GA**,TAS(5732)与 CompositePodGroup(6012)升 **beta**,DRA Preemption(5690)**新开 alpha** —— 上游一次性把生态调度器的 gang / 抢占 / 拓扑三块地盘收编,k/k 本周 11 个 sig/scheduling PR 几乎全是 gang 抢占的 GA 前打磨。
2. **生态侧同步向 Workload/PodGroup API 靠拢**:Grove alpha.14 落 Kueue 集成一期 + 层级调度 CompositePodGroup + KAI 后端,LWS v0.11.1 把 hash 组 PodGroup 所有权交还 leader 修漏;但 KEP-6277(Workload API × StatefulSet gang)刚合入即被 revert,有状态作业原生 gang 暂缓。
3. **GPU 管理面无版本动作**:gpu-operator 仅在 OpenShift DRA/MPS 权限与就绪态可观测上打补丁(深度见今日 `compute-nv-watch`),NFD / k8s-device-plugin 纯 bug 修。

**研判(WAS 原生化 vs 生态调度器)**:这是 WAS 对生态调度器**最猛的一次挤压**。gang(Volcano 的看家本领)与 workload-aware preemption 同期 GA,意味着"要 gang 就得装 Volcano/Coscheduling"的默认假设在 v1.38 后不再成立;TAS 升 beta 直接对标 Volcano/Kueue 的拓扑/网络感知编排;CompositePodGroup 把"多角色组合作业"(训练 + 推理 disagg)也纳入原生 API 范畴。生态调度器的生存空间正被压向两端——**配额/队列/公平(Kueue)** 与 **异构卡精细编排/高级抢占策略/昇腾栈(Volcano/KAI)**,纯 gang 的独占价值趋零。

- `dra-evolution` 仓本周无活动。DRA 的实质进展都在上游 k/k 与 KEP:**KEP-5690 DRA Preemption 新开 alpha(v1.38)**,KEP-5729 workload 级 ResourceClaim 已 beta(v1.37);k/k [#142202](https://github.com/kubernetes/kubernetes/pull/142202) 修 DRA consumable capacity 的 CEL 名称比较。
