# K8s 自身核心周报 2026-09-10

窗口:2026-09-03 → 2026-09-10

## 摘要(3 条以内)

1. **1.38 KEP 冲刺,in-place resize 线补上最硬的缺口**:**KEP-5554 让 in-place pod resize 与 static CPU manager policy 兼容**(target **alpha in v1.38**)——此前 Guaranteed / 整数 CPU 的负载根本用不了原地扩缩,这是 VPA in-place 后端在生产核心负载上可用的关键一块。配套一组"探针"KEP 同期推进:KEP-6318 允许**在线修改容器 probe**(in-place)、KEP-5999 h2c(HTTP/2 明文)探针 beta、KEP-4939 gRPC 探针支持 TLS beta。https://github.com/kubernetes/enhancements/pull/6330
2. **controller-runtime v0.25.0(minor,9/3)发布,引入 read-your-writes 客户端**:实验性 `ReadYourWritesConsistency` 保证写入后的读一定读到自己的写,直接消除 controller 作者最大的一类 stale-read bug;同时依赖升到 k8s v1.37、新增 `EventRecorder` 接口(**breaking**)。对我们所有基于 controller-runtime 的 operator 是升级信号。https://github.com/kubernetes-sigs/controller-runtime/releases/tag/v0.25.0
3. **Runtime 安全补丁窗口**:containerd 四条分支(v2.3.5/2.2.8/2.0.12/1.7.35,9/4)同步修 **CVE-2026-53495** 等,含剥离拉取描述符时的敏感 auth header、修 CRI 标准 I/O 流的挂起/数据竞争。周边稳定版:cluster-api v1.14.2/v1.13.6、gateway-api v1.6.2、VPA chart 0.12.0、cilium v1.21.0-pre.2(**BPF masquerade 默认开启**)。https://github.com/containerd/containerd/releases/tag/v2.3.5

## 节点 & kubelet

本周节点侧信号最密,基本都是 **1.38 方向**的推进,分三条线看:

- **in-place resize(本任务长期重点)——补 static CPU manager 兼容**:**KEP-5554 In-place update pod resources alongside static CPU manager policy**,本周更新为 target **alpha v1.38**。此前 in-place resize(KEP-1287,Linux 已 stable)在 `static` CPU manager 策略下对 Guaranteed / 整数核负载不生效;补齐后,延迟敏感 / 独占核的核心负载也能原地调整,是 VPA in-place 真正进生产的前提。https://github.com/kubernetes/enhancements/pull/6330
- **容器探针(probe)一组同期动作**:
  - **KEP-6318 允许在线(in-place)更新容器 probe**(新,9/3)——改 liveness/readiness/startup 探针不必重建 Pod,和 in-place resize 是同一"不重启改 Pod"哲学。https://github.com/kubernetes/enhancements/pull/6323
  - **KEP-5999 h2c(HTTP/2 cleartext)容器探针 → beta v1.38**。https://github.com/kubernetes/enhancements/pull/6338
  - **KEP-4939 gRPC 探针支持 TLS → beta v1.38**。https://github.com/kubernetes/enhancements/pull/6336
- **拓扑 / 资源管理**:
  - **KEP-6007 NUMA 利用率感知的 topology manager 策略选项**(新,9/8)——给 topology manager 增加"按 NUMA 节点利用率"分配的 policy option,对齐 CPU/内存 NUMA 亲和的通用节点能力(非 AI 专用)。https://github.com/kubernetes/enhancements/pull/6332
  - **KEP-5825 CRI List 流式接口 → beta v1.38**——大规模节点上 List 容器/Pod 沙箱走流式,降 kubelet↔runtime 单次响应体积。https://github.com/kubernetes/enhancements/pull/6146
- **承上仍在推进(本窗口有活动、非新增)**:KEP-6313 Hermetic(网络隔离)Pod、KEP-6303 in-place resize 上 Windows、KEP-5972 Dynamic Containers、KEP-6252 Hugepages Reservation、KEP-6030 内存卷动态 resize(beta)、KEP-5683 drain 写 Node conditions、KEP-6063 Per-Pod PID Limit。

## 自动扩缩容(VPA / CA / Karpenter)

- **in-place resize 线**:见上 KEP-5554(static CPU 兼容)+ KEP-6318(在线改探针)。这两条合起来把"不重启就能调 Pod 资源与健康检查"的能力面进一步补全,是 VPA 走 in-place 后端生产可用的持续拼图。
- **HPA**:**KEP-6003 可配置 HPA sync period**(sig-autoscaling)本周有活动——把 HPA 控制回路的同步周期做成可配置(默认 15s),对大规模 HPA 场景的 apiserver 压力 / 响应速度是可调项。仍 open,未定版本。https://github.com/kubernetes/enhancements/pull/6004
- **VPA**:发布 **vertical-pod-autoscaler-chart-0.12.0**(9/5),Helm chart 版本更新;VPA 组件本体本窗口无新 minor,无能力级变化。https://github.com/kubernetes/autoscaler/releases/tag/vertical-pod-autoscaler-chart-0.12.0
- **cluster-api v1.14.2 / v1.13.6(9/8)**:补丁版。看点仅一处新特性——manager 加 `--tls-curve-preferences` flag(安全加固);其余为 KCP rollout(从 CAPI v1.11 升级后的 rollout 修复)、ClusterClass 生命周期 hook、grpc/x/crypto CVE 依赖修。管理集群支持面仍 v1.33→v1.37。https://github.com/kubernetes-sigs/cluster-api/releases/tag/v1.14.2
- **Cluster Autoscaler / Karpenter**:本窗口无新 release,无实质变化。

  - **建议纳入下一次节点镜像滚动**(涉及 CVE + 凭据 header 泄漏加固)。https://github.com/containerd/containerd/releases/tag/v2.3.5

## API Machinery & Operator 生态

- **controller-runtime v0.25.0(minor,9/3)** —— 本周 Operator 生态最重要的一条:
  - **read-your-writes 客户端(实验)**:`Client.EnableReadYourWritesConsistency: new(true)` 后,默认 cache-backed client 的读一定反映自己刚写的内容,消除"写完立刻读读到旧值"这一类最常见的 controller bug。https://github.com/kubernetes-sigs/controller-runtime/issues/3320
  - **breaking**:依赖升到 k8s.io/* v1.37;新增 `EventRecorder` 接口(事件记录 API 变更,升级需适配)。
  - 其他:fakeclient 支持 Apply 的 scale 子资源与全局 ResourceVersion 计数器、新增 `TypedInformer` source、可用 `port: -1` 关闭 webhook server、client-go REST 指标可选开启、修 cache `Start()` goroutine 泄漏。https://github.com/kubernetes-sigs/controller-runtime/releases/tag/v0.25.0
- **api-machinery 新/续 KEP**:KEP-6264 etcd 存储对象压缩、KEP-6315 apiserver 加权负载均衡(两者上周已记,本窗口继续有活动,状态无跃迁)。
- **kubebuilder / operator-sdk**:本窗口无新 release。
